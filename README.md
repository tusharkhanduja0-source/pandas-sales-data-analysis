# pandas-sales-data-analysis
A beginner-friendly Data Analytics project using Python and Pandas to analyze retail sales data. Covers data inspection, data cleaning, data transformation, exploratory data analysis (EDA), KPI calculations, pivot tables, customer analysis, monthly sales trends, and CSV data export.

# Pandas Sales Data Analysis Project

## Project Overview
This project focuses on analyzing retail sales data using Python and Pandas.

It covers data inspection, data cleaning, data transformation, Exploratory Data Analysis (EDA), KPI calculations, pivot tables, and business insights.

## Dataset Information
- Total Records: 16
- Original Columns: 9
- Time Period: January – March 2026
- Cities: Delhi, Gurgaon, Rewari
- Categories: Electronics, Grocery, Clothing
